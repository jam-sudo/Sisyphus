## Current models (`models/`)

- `direct_pk/xgboost_cmax.json` — ML Cmax (clean, N=1,028).
- `direct_pk/meta.json` — meta-learner weights, v3_clean.
- `adme/xgboost_fup_v2.json` — fup predictor (clean).
- `adme/xgboost_peff.json` — Peff predictor (clean).
- `adme/xgboost_clint.json` — CLint predictor (clean, scaffold CV R²=0.35 / random CV R²=0.42).
- `adme/xgboost_clint_v3_biogen.json` — CLint with Biogen 3K+ expansion (random CV R²=0.55); **NOT used in this repo** (error cancellation). Usable in other repos. ⚠ scaffold CV not measured.
- `adme/xgboost_vdss.json` — VDss predictor (production, base of the 4th track).
- `adme/xgboost_vdss_v2.json` + `_meta.json` — VDss v2 experimental (training / LOOCV only; not on production path).
- `adme/xgboost_bioavailability.json` + `_meta.json` — F% predictor (trained only, NEGATIVE result, production unused).
- `adme/xgboost_clearance_v1.json`, `adme/xgboost_thalf_v1.json` — post-VDss negative experiments (archival).
- `surrogate/cmax_mlp_{0..4}.eqx` — neural surrogate ensemble (R²=0.9995).
- `sbi/multi_drug_nsf.pt` — production NPE (Phase 2.0.5 v2, 94 epochs, 110k samples). v1 backed up as `_v1.pt`, v3 (NEGATIVE) archived as `_v3.pt`.
- `sbi/hierarchical_nsf_2k.pt` — Track C1 hierarchical NPE (2kθ, 76 epochs, 220k samples).

## Engine (`src/sisyphus/engine/`)

- `compiler.py` — ODE compiler (`CompiledODE`, `ResolvedParams`).
- `flux.py` — 6 flux types (flow, clearance, transit, absorption, diffusion, active_transport).
- `solver.py` — SciPy LSODA.
- `solver_jax.py` — JAX/Diffrax Kvaerno5 (vmap MC).
- `params_jax.py` — JAX-compatible flat parameter struct.
- `rhs_jax.py` — pure-JAX ODE RHS (6 flux types vectorized).
- `uncertainty.py` — MC propagation (backends: scipy / jax / surrogate).
- `surrogate.py` — neural surrogate MLP (Equinox).

## TDM (`src/sisyphus/regimen/`)

- `tdm.py` — Bayesian update API (`method ∈ {importance_sampling, ibis, enkf, sbi}`).
- `tdm_ibis.py` — IBIS (sequential MC + MCMC rejuvenation).
- `tdm_enkf.py` — Ensemble Kalman Filter.
- `tdm_sbi.py` — SBI dispatch, `sbi_update`, optional `sbi_reweight=True`.

## SBI (`src/sisyphus/sbi/`)

- `priors.py` — BoxUniform prior over (log10_clint_shift, fup, log10_peff_shift).
- `simulator.py` — `EngineSimulator` wraps scipy engine + `apply_theta_to_drug`.
- `amortizer.py` — `train_npe`, `save_result`, `load_result` (sbi library, SNPE/NSF).
- `sbc.py` — rank-based SBC with KS test + coverage.
- `physiology_generator.py` — P4 continuous physiology generator (`generate_physiology(BW, age)`).
