# Bridge B / B1.x Phase-0 — zonal GSH-pool depletion

> **Context.** First **B1.x** sub-project, deepening the B1 zonal reactive-metabolite hazard probe (PR #82) from a *static* detox capacity to a finite, consumable, slowly-regenerating **GSH pool** — the actual acetaminophen mechanism the B1 static threshold was an explicit proxy for (B1 spec §1, §6). Phase-0 stays **mechanistic and qualitative**, **harness-isolated**, headline **2.731 untouched**, post-processor only (GSH and the reactive metabolite are NOT engine species). **Direction set by the 2026-06-18 ultrathink:** lead with the distinction that is *analytically guaranteed* — a depleting pool makes the hazard **history-dependent**, which the static (pointwise-integral) model provably cannot be — and treat the depletion *cliff* as an empirical, honest-negative-capable secondary. This avoids two confounds the first draft contained (a path-test whose "static control" is not actually controlled, and a sharpness metric rigged by the static model's hard-zero floor).

## 1. Purpose & non-goals

**Purpose.** Demonstrate, on the real axial engine + a per-zone GSH-pool post-processor, that a *dynamic* finite detox pool adds structure the B1 static capacity cannot represent:

1. **History-dependence (centerpiece, analytically clean).** The static hazard `H = ∫ f(C_u(t)) dt` is a *pointwise-integral functional*, hence **provably invariant to any reordering of the concentration trajectory** (same values, different order ⇒ identical `H`). The GSH-pool hazard is **not** — it integrates the pool's depletion history. So a pure ordering swap (same concentration value-distribution, different temporal order) leaves the static hazard exactly unchanged while moving the dynamic hazard: an airtight, confound-free signature of pool memory.
2. **Path-dependence, physical arm.** The same total dose as one bolus vs two spaced half-doses yields different hazard. Because the *concentration envelope itself differs* between the two protocols, the **static model is also path-sensitive** here — so the dynamic signature is the **excess** path-dependence over the static (envelope-only) baseline, not a naive "static is flat" claim.
3. **Depletion cliff (secondary, empirical).** Once local NAPQI formation outruns local GSH resynthesis the pool drains, scavenging efficiency falls *as the pool empties* (an autocatalytic feedback), and escaped covalent binding rises steeply — potentially sharper than the static threshold ramp. Reported via a fair transition-width metric; honest-negative if it does not out-sharpen the static curve.
4. **NAC-precursor protective lever (analytically clean).** Formation is independent of GSH, so raising the baseline pool `GSH0` lowers the escape fraction pointwise ⇒ hazard is strictly monotone-decreasing in `GSH0` — the clinical antidote analog, provable.

All while reproducing the acetaminophen zonal pattern (pericentral bioactivation-high + pericentral GSH-low → zone-3/centrilobular vulnerability) and re-confirming the B1 orthogonality result (bulk parent PK invariant to the zonation that moves the per-zone hazard, DE-50).

**Non-goals (explicit).**
- **Mechanistic/qualitative demonstration, NOT a calibrated toxicity number.** No DILI probability, no quantitative threshold dose vs clinical data. An honest-negative (no cliff sharpening; pool memory below the noise floor) is a first-class outcome (cf. DE-49/DE-50).
- **Harness-isolated.** No `predict()` / `reference_man.yaml` / holdout / `src/sisyphus/engine/` / `expand_axial` change. Headline **2.731 bit-identical**. Synthetic axial skeleton.
- **GSH and the reactive metabolite are NOT engine species.** Per-zone formation + pool depletion are a **post-processor** on the parent profile. As in B1, the bioactivation flux does not consume parent mass in the engine — valid because the bioactivation fraction is minor (`fm_bioactivation ≪ 1`; for APAP the CYP/NAPQI route is ~5–15% of clearance, the rest glucuronidation/sulfation). Transported reactive-metabolite as a convected engine species remains a *separate* B1.x feasibility spike.
- **Single bioactivation enzyme + single GSH pool** on the synthetic skeleton (not the real multi-enzyme ECM liver). No mitochondrial/ROS amplification beyond the pool.
- **No parameter tuned to manufacture an effect.** `k_syn` (resynthesis rate) and `τ` (divided-dose spacing) are **pinned from physiology a priori** (§3.4), *before* checking whether a cliff/path-separation appears. Synthetic-param selection is for mechanism *visibility* on synthetic skeletons (documented), in the discipline of B1/zonation/PGx — never a fit to clinical data.

## 2. Background: from static capacity to a depleting pool

B1 modeled per-zone detox as a **constant** capacity: `H_i = ∫ max(0, R_form,i(t) − Vmax_detox,i) dt`. This is a pointwise functional of `C_u,i(t)` — its value depends only on the *multiset* of concentrations visited, not their order, and the instantaneous escaped flux ignores all prior exposure.

The real glutathione mechanism is a **finite, consumable pool with slow resynthesis**. Per zone i (inlet→outlet = periportal→pericentral):

- **formation** (reused from B1): `R_form,i(t) = Vmax_bio,i · C_u,i(t) / (Km_bio + C_u,i(t))`, `Vmax_bio,i ∝ local CYP abundance` (zonatable, pericentral-high);
- **pool dynamics**: `dGSH_i/dt = k_syn·(GSH0_i − GSH_i) − R_form,i(t)·GSH_i/(Kg + GSH_i)` — first-order resynthesis toward the baseline `GSH0_i` (zonatable, pericentral-**low**) minus saturable scavenging consumption (a unit of NAPQI consumes a unit of GSH; the `GSH/(Kg+GSH)` factor makes scavenging collapse as the pool empties);
- **hazard** (escaped covalent-binding flux): `H_i = ∫ R_form,i(t)·(1 − GSH_i(t)/(Kg + GSH_i(t))) dt` — the fraction of formed NAPQI that escapes scavenging because the pool is depleted, the covalent-binding/toxicity proxy. Same units/meaning as the B1 hazard, so G1/G2/G-NAC carry over directly.

**Two structural facts the ultrathink established:**
- **The steady state is smooth, not a bifurcation.** At `GSH=0` the consumption term vanishes (you cannot consume an empty pool), so `dGSH/dt = k_syn·GSH0 > 0`: the pool always recovers and `GSH*(R) > 0` for every finite formation rate `R`. The *steady-state* escape fraction is a smooth function of `R` — there is **no** discontinuous threshold.
- **The cliff is a transient pool-budget effect.** Sharpness arises only when resynthesis is **slow relative to the exposure pulse**: the pool then behaves as a near-fixed budget that a large pulse overwhelms, and the `GSH/(Kg+GSH)` consumption term gives an **autocatalytic crash** (draining accelerates as the pool empties). This is physiologically correct (GSH turnover ~hours ≫ Tmax) but makes the cliff **regime-dependent on `k_syn`** — hence the a-priori pinning (§3.4) and the honest-negative framing.

**Why bulk PK cannot see any of this (DE-50 closure).** Total parent bioactivated = total hepatic extraction, invariant to the CYP spatial distribution (plug-flow, DE-50). The redistribution that leaves bulk parent Cmax/AUC unchanged still moves the per-zone hazard profile — the Bridge-B orthogonal-information claim, re-confirmed here for the dynamic endpoint.

## 3. Method

### 3.1 Per-zone parent profile (reuse)
Reuse B1's `_parent_profile_by_zone` (importlib-load `scripts/probe_zonal_hazard.py`, the established pattern): build the synthetic axial liver (`_axial_graph`, PR #79), solve a single oral dose, return per-sub-tank unbound parent `C_u,i(t)` (= `fup · c_node`) inlet→outlet plus the time grid. Bulk parent `E` via B1's `bulk_E` (for the G2 arm).

### 3.2 The GSH-pool hazard post-processor (pure, tested)
`gsh_pool_hazard(c_u_by_zone, vmax_bio_by_zone, km_bio, gsh0_by_zone, k_syn, kg, time) -> list[float]` in `src/sisyphus/validation/pgx_metrics.py`. Per zone: integrate the §2 pool ODE with a **self-contained fixed-step RK4** (linear interpolation of `C_u,i(t)` between grid points; an internal refined step independent of the engine's `t_eval` density; `GSH` clamped ≥ 0 against the autocatalytic crash), then trapezoid-integrate the escaped-flux hazard. Numpy-only, deterministic, no scipy — trivially unit-testable against a hand-worked constant-`C_u` steady state. `vmax_bio_by_zone`/`gsh0_by_zone` come from `zonation_weights × total` (independently zonatable). B1's static `zonal_hazard` is **left untouched** — the probe contrasts dynamic vs static.

### 3.3 The history/order test (centerpiece — pure, no engine)
`_ordering_profiles(levels, dt, n_grid) -> (t, c_asc, c_desc)`: two synthetic single-zone concentration trajectories over one time grid that visit the **same value-multiset** `{levels}` (each held `dt`) in **ascending** vs **descending** order. By construction `∫ f(C) dt` is identical for the two (a measure-preserving reordering), so the **static** `zonal_hazard` returns the same value for both (numerically, to a tight tolerance). The **dynamic** `gsh_pool_hazard` integrates the pool through the two orderings and returns **different** values. Pure post-processor demonstration — does not touch the axial engine at all; the cleanest possible isolation of pool memory.

### 3.4 The divided-dose profile (physical path arm) + a-priori pinning
`_divided_dose_profile_by_zone(..., n_splits, tau_h)`: solve the axial ODE in segments — administer `dose/n_splits` at t=0, integrate to `tau_h`, **add** the next `dose/n_splits` to the administration-node state, re-solve from the carried state, repeat; concatenate per-sub-tank `C_u,i(t)` onto one monotonic time grid. Pure harness-level segmentation of the existing compiled ODE solve — no `regimen`/engine surface. Equal total dose (mass) to the bolus arm; the parent envelopes differ under saturable first-pass — which is exactly why the **static model is also path-sensitive** here and the gate measures *excess* over it (§4).

**A-priori physiological pinning (documented, not tuned):** `k_syn = ln2 / t½_GSH` with `t½_GSH ≈ 2–4 h` (hepatic GSH turnover; order-of-magnitude literature) ⇒ `k_syn ≈ 0.2–0.35 h⁻¹`. `τ` (divided-dose spacing) set on the **recovery timescale** (a few hours) so partial regeneration occurs between doses. Both fixed before observing any cliff/path outcome; recorded in the report. The bioactivation/detox zonation and totals reuse the B1 acetaminophen config.

### 3.5 The sweeps (`scripts/probe_gsh_depletion.py`)
- **Order sweep (G-order, centerpiece):** static vs dynamic hazard on `_ordering_profiles`; record `|Δ|` for each model.
- **Zonation sweep (G1/G2):** vary bioactivation and `GSH0` zonation (uniform/pericentral/periportal × ratio), totals fixed; record per-zone GSH-hazard profile (peak zone + magnitude) AND bulk parent `E`.
- **Path sweep (G-time, physical):** fixed total dose above the cliff; bolus vs `n_splits=2`, `tau_h` spaced; record the dynamic and static `H_bolus/H_divided` ratios and the per-zone min-GSH (depletion-depth secondary).
- **Dose sweep (G-cliff, secondary):** APAP config; per-zone `maxH` vs dose for **both** dynamic pool and B1 static `zonal_hazard`; compute each curve's transition width (§4).
- **Protective-lever sweep (G-NAC):** scale `GSH0` up (×1.5, ×3); record hazard reduction at a fixed supra-threshold dose (monotone).

## 4. Metric & pre-registered gates

- **G-order — pool memory (centerpiece, analytically clean).** On `_ordering_profiles` the **static** hazard for ascending vs descending is equal to within a tight numerical tolerance (`|ΔH_static| / H_static` below a pinned ε, the measure-preserving-reordering invariant), **while** the **dynamic** hazard differs materially (`|ΔH_dynamic| / H_dynamic` above a pinned threshold). Proves the dynamic model carries order/history information the static model structurally cannot. (Near-fails only if pool memory is below the engine/integration noise floor — an honest-negative.)
- **G1 — localization (sanity).** APAP config → hazard peaks at the outlet zone (zone 3, pericentral) and that zone's GSH depletes deepest; flipping the gradients moves the peak.
- **G2 — local matters, bulk doesn't (DE-50 closure, carried).** Holding total bioactivation enzyme fixed, varying its zonation leaves bulk parent `E` ~invariant (`|ΔE|` below a pinned small tolerance) **while** the per-zone GSH-hazard peak-zone and/or magnitude change materially.
- **G-time — excess path-dependence (physical).** Report both `(H_bolus/H_divided)_dynamic` and `(H_bolus/H_divided)_static`. The signature is the **excess** `(H_bolus/H_divided)_dynamic − (H_bolus/H_divided)_static`; the dynamic ratio is expected to exceed the static (envelope-only) ratio when `τ` permits partial recovery. Reported with sign; honest-negative if the excess is within tolerance of zero. (Not framed as "static is flat" — the static path effect is explicitly measured, not assumed zero.)
- **G-cliff — dynamic sharpness vs static ramp (secondary, empirical).** On the same APAP config and dose grid, compute the transition width (dose span from 10%→90% of each curve's own `maxH`) for the dynamic and static `maxH(dose)` curves. The hypothesis (autocatalytic depletion ⇒ narrower dynamic transition) is **reported, not presupposed**: state which is sharper and by how much. Metric is immune to the static model's hard-zero floor (normalized to each curve's max). Honest-negative if dynamic is not narrower.
- **G-NAC — protective lever (analytically clean).** Raising `GSH0` monotonically lowers `maxH` at a fixed supra-threshold dose. Provable (`R_form` independent of GSH); a regression-style monotonicity check.
- **Honest-negative path:** if G-order shows no separation, or the cliff does not sharpen, or the path-excess is ~zero, report as-is. No parameter tuned to manufacture any effect; `k_syn`/`τ` pinned a priori.
