# Pimecrolimus Cmax training-matrix adjudication (2026-09-24)

The pinned [Omega source workbook](https://github.com/jam-sudo/Omega/blob/08a45047a2b5dcdca8c9a8f36ff1fe3b50ed3d6d/data/external/mmpk/approved.xlsx), row 3042, records oral pimecrolimus 15 mg with Cmax **41.2 ng/mL**. The fitted [Omega Cmax aggregate](https://github.com/jam-sudo/Omega/blob/08a45047a2b5dcdca8c9a8f36ff1fe3b50ed3d6d/data/ml/clinical/mmpk_clean.csv) is 0.0412 mg/L (`n_studies=1`). The [original 15 mg study](https://pubmed.ncbi.nlm.nih.gov/16467136/) describes parent pimecrolimus **blood** concentrations and high blood-cell distribution. This label is not the model's parent **plasma** Cmax target.

Workbook rows 3043–3044 give 60 mg and 30 mg Cmax values of 147.5 and 79 ng/mL. Their [original oral-dose study](https://pubmed.ncbi.nlm.nih.gov/14606933/) reports blood Cmax. Those two additional doses appear only in exploratory `mmpk_expanded_{full,v2}.csv`; all three pimecrolimus rows in each exploratory file and the single derived `mmpk_pbpk_features.csv` row were quarantined. The original Omega file stays byte-pinned for provenance and conservative training-membership screening. No assumed blood-to-plasma factor or development label was used as a replacement.

As a matrix check against over-exclusion, the separate hydroxychloroquine 155 mg row (Omega workbook row 1955, 46 ng/mL) was **retained**: a [regulatory review of the original study](https://www.pmda.go.jp/drugs/2015/P20150618003/780069000_22700AMX00692000_A100_1.pdf) distinguishes the 46 ng/mL **plasma** Cmax from the 244 ng/mL whole-blood Cmax. Matrix status is assigned to the source arm, not inferred from the drug class.

After this one-row fitted exclusion, Cmax training has **909** rows. Five-fold CV AAFE changed **3.362 → 3.359**. The repeatedly accessed N=73 development benchmark changed direct ML AAFE **3.1230 → 3.0418** and Meta AAFE **2.8538 → 2.8496**; the conditional paired Meta/ML ratio is **0.9368** (bootstrap 95% CI **0.8208–1.0653**). These development changes are diagnostic, not independent external validation.
